# Usage Guide

Task CLI is a lightweight command-line tool to manage your daily tasks. Below are the available commands:

## Commands

- **`add <title>`**: Add a new task to your task list.
- **`list`**: Display all current tasks along with their status.
- **`done <id>`**: Mark a specific task as completed by its ID.
- **`remove <id>`**: Delete a task from the list by its ID.
